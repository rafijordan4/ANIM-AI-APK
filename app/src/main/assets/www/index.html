Cara menggunakan ANIM AI

  1. Tulis ide cerita dan masukkan Gemini API key. Untuk riset online, deploy backend lalu isi URL-nya.
  2. Periksa dan edit karakter serta adegan. Centang persetujuan.
  3. Produksi membuat visual SVG untuk tiap adegan.
  4. Putar preview, lalu ekspor MP4 tanpa audio.

Catatan: Gemini key masih dimasukkan langsung di aplikasi. Tavily memakai backend proxy agar key riset tidak terekspos. Pexafy tidak diaktifkan. Jangan membagikan APK yang berisi key pribadi.
